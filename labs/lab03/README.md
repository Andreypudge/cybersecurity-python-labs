# Лабораторна робота №3: Прикладні бібліотеки Python для побудови вебзастосунків
**Варіант 9**: Облік часу опрацювання повідомлень

## 1. Опис предметної області та параметри варіанта
Сервіс реалізує Web API на базі FastAPI та SQLite для ведення обліку тривалості перевірки повідомлень про події безпеки.

* **Категорії джерел повідомлень (`categories`)**:
  * `1` — `siem`
  * `2` — `helpdesk`
  * `3` — `monitoring`
* **Шаблон назви (`title`)**: «Вимірювання опрацювання» (наприклад, `Вимірювання опрацювання 01`)
* **Одиниця вимірювання (`unit`)**: `minutes` (тривалість перевірки у хвилинах)
* **Поріг оперативного реагування (`threshold`)**: `15.0` хв
* **Тип та обмеження поля `value`**: скінченне дійсне число `float` (`REAL` у SQLite), значення `value >= 0`
* **Допустимі статуси (`status`)**: `new`, `in_progress`, `done`

## 5. Приклади основних запитів

### 5.1. Службові маршрути
Перевірка доступності сервісу:
```bash
curl -i "http://127.0.0.1:8000/ping"
```

Отримання інформації про автора:
```bash
curl -i "http://127.0.0.1:8000/student"
```

### 5.2. Робота з категоріями
Отримання списку категорій:
```bash
curl -i "http://127.0.0.1:8000/categories"
```

Створення нової категорії:
```bash
curl -i -X POST "http://127.0.0.1:8000/categories" \
  -H "Content-Type: application/json" \
  -d '{"name": "external_scanner"}'
```

Видалення порожньої категорії:
```bash
curl -i -X DELETE "http://127.0.0.1:8000/categories/4"
```

### 5.3. Робота із записами (CRUD)
Створення окремого запису:
```bash
curl -i -X POST "http://127.0.0.1:8000/records" \
  -H "Content-Type: application/json" \
  -d '{"code": "V09-TEST", "title": "Вимірювання опрацювання тестове", "category_id": 1, "value": 14.5, "status": "new"}'
```

Отримання одного запису за ID:
```bash
curl -i "http://127.0.0.1:8000/records/9"
```

Повне оновлення запису (PUT):
```bash
curl -i -X PUT "http://127.0.0.1:8000/records/9" \
  -H "Content-Type: application/json" \
  -d '{"code": "V09-TEST-UPD", "title": "Оновлене вимірювання", "category_id": 2, "value": 8.0, "status": "done"}'
```

Видалення запису:
```bash
curl -i -X DELETE "http://127.0.0.1:8000/records/9"
```

### 5.4. Фільтрація, пошук та пагінація
Фільтрація за статусом, мінімальним часом і пагінація:
```bash
curl -i "http://127.0.0.1:8000/records?category_id=1&status=new&min_value=15.0&limit=5&offset=0"
```

Буквальний пошук підрядка в назві:
```bash
curl -i "http://127.0.0.1:8000/records?q=%D0%BE%D0%BF%D1%80%D0%B0%D1%86%D1%8E%D0%B2%D0%B0%D0%BD%D0%BD%D1%8F"
```

### 5.5. Пакетне додавання в межах однієї транзакції
Створення масиву записів:
```bash
curl -i -X POST "http://127.0.0.1:8000/records/bulk" \
  -H "Content-Type: application/json" \
  -d '[
    {"code": "V09-BULK1", "title": "Пакетне вимірювання 01", "category_id": 1, "value": 11.0, "status": "new"},
    {"code": "V09-BULK2", "title": "Пакетне вимірювання 02", "category_id": 2, "value": 13.5, "status": "in_progress"}
  ]'
```
